# Naming SaaS — 5 propuestas para reemplazar "Caja Diaria"

> **Contexto:** la app es un tracker financiero personal (movimientos,
> presupuestos, proyección de saldo) que en v2 suma modo comercial
> (clientes, ventas de contado/crédito, cuentas por cobrar). Mercado
> inicial: Perú (PEN, es_PE). Meta: SaaS con ingresos recurrentes.
>
> **Criterios de selección:**
>
> 1. Pronunciable y escribible sin ambigüedad (dictable por teléfono).
> 2. Conectado al problema (flujo de caja, solvencia, cobros) sin ser
>    descriptivo genérico.
> 3. Protegible como marca (INDECOPI, clases 9/36/42).
> 4. Sirve para ambos modos: personal y comercial.
> 5. Escalable fuera de Perú a mediano plazo.

---

## 1. Fluya ⭐ (recomendada)

Del **flujo de caja**, el concepto central del producto. Funciona como
forma verbal ("que tu plata fluya"): moderno, una sola palabra, tono
SaaS, neutro entre persona y negocio.

| | |
|---|---|
| Dominios a verificar | `fluya.app`, `fluya.pe`, `fluya.lat` · fallback: `fluyapp.com` |
| Handles | `@fluyaapp` |
| Tagline | *"Tu flujo de caja, en claro."* |
| Riesgo | Es forma verbal del diccionario → protección de marca moderada; verificar clase 36/42 en INDECOPI |

## 2. Solvio

Nombre **inventado**: *solvencia* + *sol* (la moneda peruana). Comunica
salud financiera sin decirlo literalmente. Los nombres inventados son los
más protegibles como marca y los que mejor escalan internacionalmente.

| | |
|---|---|
| Dominios a verificar | `solvio.app`, `solvio.pe` · fallback: `getsolvio.com` |
| Handles | `@solvioapp` |
| Tagline | *"Solvencia para tu bolsillo y tu negocio."* |
| Riesgo | Bajo; verificar colisiones menores (pueden existir pymes "Solvio" en otros rubros) |

## 3. CuentasClaras

Del refrán *"las cuentas claras conservan amistades"*. Encaja
perfectamente con el módulo de **cuentas por cobrar** de v2 y con la
promesa de transparencia. Recall inmediato en todo LatAm.

| | |
|---|---|
| Dominios a verificar | `cuentasclaras.com`, `cuentasclaras.app`, `cuentasclaras.pe` |
| Handles | `@cuentasclaras` |
| Tagline | *"Cuentas claras, negocios largos."* |
| Riesgo | Largo para dominio y algo descriptivo → protección de marca débil. Fuerte en marketing, débil en registro |

## 4. Cóbralo

**Imperativo** directo al dolor del modo comercial: registrar y cobrar
las cuentas por cobrar. Energético, memorable, muy vendedor.

| | |
|---|---|
| Dominios a verificar | `cobralo.app`, `cobralo.pe`, `cobralo.lat` (sin tilde) |
| Handles | `@cobraloapp` |
| Tagline | *"Registra, proyecta y cóbralo."* |
| Riesgo | Sesgo comercial: puede sonar agresivo para el usuario del modo personal; verificar apps de cobranza con nombres similares |

## 5. Kori

**"Oro" en quechua** (Qori, como en Qoricancha). Corto, exótico pero
fácil de pronunciar y escribir, con raíz peruana fuerte y cara
internacional. Ideal si la visión es construir marca, no describir
función.

| | |
|---|---|
| Dominios a verificar | `kori.app` (probablemente tomado) → `kori.pe`, `koriapp.com`, `korifinanzas.com` |
| Handles | `@koriapp` |
| Tagline | *"El oro de tu negocio, bajo control."* |
| Riesgo | "Kori" existe como nombre propio y como marca en otros rubros (suplementos, moda); verificar clase 36/42 |

## Tabla comparativa

| Nombre | Idea central | Tono | Dominio candidato | Protegibilidad |
|---|---|---|---|---|
| **Fluya** | Flujo de caja | Moderno, SaaS | `fluya.app` / `.pe` | Media |
| **Solvio** | Solvencia + sol | Serio, financiero | `solvio.app` | Alta (inventado) |
| **CuentasClaras** | Refrán popular | Cercano, confiable | `cuentasclaras.com` | Baja (descriptivo) |
| **Cóbralo** | Imperativo de cobro | Comercial, enérgico | `cobralo.app` | Media |
| **Kori** | Oro en quechua | Marca, premium | `kori.pe` / `koriapp.com` | Media-alta |

**Recomendación:** **Fluya** como primera opción (equilibrio entre
significado, tono SaaS y disponibilidad probable de `.app`/`.pe`) y
**Solvio** como alternativa si se prefiere una marca inventada más
protegible a largo plazo.

## Descartados (y por qué)

| Nombre | Motivo del descarte |
|---|---|
| **Yapa** | Demasiado similar a **Yape** (app de pagos de BCP, masiva en Perú) → conflicto de marca casi seguro |
| **Kipu / Quipu** | Ya existen empresas de software con ese nombre (health tech, contabilidad) |
| **Lucra** | Existe Lucra Sports en EE.UU. → riesgo si se expande; verificar antes de reconsiderar |
| **Tanda / Junta** | Fintechs existentes con ese nombre; "junta" además tiene connotación política |
| **Caja Diaria** | Descriptivo y genérico: no protegible como marca y poco comercial (nombre actual) |

## Checklist antes de apartar el dominio

1. **Disponibilidad de dominio:** verificar en Namecheap/Porkbun y el
   `.pe` en [punto.pe](https://punto.pe). Registrar también variantes
   comunes (`.com`, `.app`, `.pe`).
2. **Handles sociales:** verificar Instagram, TikTok, X, Facebook y
   LinkedIn con namechk.com o similar. Priorizar handle idéntico al
   dominio.
3. **Marca en Perú:** búsqueda fonética en INDECOPI
   ([servicios.indecopi.gob.pe](https://servicios.indecopi.gob.pe)),
   clases 9 (software), 36 (servicios financieros) y 42 (SaaS).
4. **Colisiones fintech:** buscar el nombre en Google Play y App Store;
   evitar cualquier app financiera con el mismo nombre aunque esté en
   otro país.
5. **Significado cruzado:** confirmar que el nombre no significa algo
   indeseable en otros países de LatAm (relevante para expansión).
